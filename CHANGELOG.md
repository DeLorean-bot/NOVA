# Changelog

## 0.8.25

- Opt-in community ratings use encrypted GitHub Gist ballots and a public aggregate feed. Sharing requires a GitHub sign-in.
- The embedded player fullscreen button uses NOVA's fullscreen layout without magnifying the controls.

## 0.8.24

- New personal scores are available on the screen after watching. Existing scores can still be edited in My ratings.

## 0.8.23

- NOVA checks for new releases every minute while open, and again when the connection returns. It announces a new release and downloads installed-app updates in the background.

## 0.8.22

- Double-clicking the video uses NOVA's fullscreen layout and keeps player controls at their regular size.
- The pause panel can identify actors from the current frame using local recognition. It shows actor portraits and uses scene or music information when available.
- Added optional community ratings and a home shelf. NOVA enables them once a community server is configured. Sharing requires consent and can be revoked in Settings.

## 0.8.2

- English and Russian interface languages, switchable in Settings.
- A shorter search panel with the search field kept in place.
- Liquid Glass on feedback notifications and an immediate response on poster actions.
- A quieter startup with the NOVA mark, wordmark, and a blur transition.
- A background GitHub release check. Available updates appear in Settings.
- Removed the How to watch page.

## 0.8.1

- Renamed the application to NOVA and added monochrome marks for both themes.
- Preserved the existing local profile and library.
