# Проверка интерфейса

Приложение проверено в Electron на Windows: обзор, фильмы, сериалы, пустая/заполненная коллекция, карточка фильма, поиск с результатами и без, опечатка из примера пользователя, внутренний сайт, справка, окно 980×680, плеер и история. Размер основного окна 1440×940. Отчёт: `test-results/audit/report.json`.

Проверены уникальность ID карточек и единичность действий, отсутствие бокового блока сайтов, отсутствие дублирующего футера в поиске, единые меню без выбранной опции, ввод адреса, Ctrl L, сортировка, избранное, история и отсутствие горизонтально обрезанных контролов.

Сетевой адблок проверен на локальной странице: запрос VAST отменён до обращения к серверу, баннер скрыт, обычный скрипт выполнен; переключение защиты восстанавливает запрос. Отдельно проверено реальное воспроизведение с блокировкой.

Stageshow: за основу взят `examples/dark-hero`, копия сохранена в `design/dark-hero-original`. Сохранены и адаптированы Surface steps, Window, Row, Collapse и poster. Добавлена отдельная компактная композиция 358px, показывающая один результат. Демо обозначено как пример и не содержит кнопки, выдающей себя за действие.

Контактные листы демонстрации получены на широкой и компактной композициях; gate не нашёл нарушений из категории never-intentional. Полнота временной выборки была inconclusive из-за пропусков 36–40ms на этой машине: это не доказательство безупречной плавности. Статические состояния и контактные листы просмотрены визуально. Физическое сенсорное устройство и весь ассортимент внешних провайдеров не проверялись.

Geologica и Material Symbols упакованы локально. WebGPU-маска успешно получила статус ready; fallback и reduced-motion предусмотрены. Родные контуры символов взяты из набора Google, иконки не рисовались вручную.

Версия 0.3: визуально проверены обе темы — обзор, поиск, меню, карточка, справка и окно 980×680. Переключение темы сохраняется после перезапуска. В reduced motion поиск не создаёт canvas. Отчёт: `test-results/themes/report.json`, ошибок renderer нет.

Три входа в полноэкранный режим проверены в Electron: кнопка приложения, F11 в нативном плеере и HTML requestFullscreen. Во всех случаях боковая панель, вкладки, панель окна и панель плеера скрыты; WebContentsView получает bounds {x:0,y:0,width:1920,height:1080}, равные размеру экрана. Esc и повторный F11 возвращают оболочку. Эти проверки подтверждают компоновку, а не доступность каждого фильма у провайдера.

Дополнение 0.3: online-поиск отделён от популярной подборки. Live-проверка «Молодой Шерлок» / Young Sherlock / 5591410 и двух ссылок пользователя прошла, включая получение метаданных до первого поиска. Проверены следующие страницы выдачи и разделов фильмов/сериалов, отсутствие повторных ID и очистка истории. Отчёт `test-results/library/report.json`. После изменений заново прошёл общий аудит 15 экранов, в том числе заполненная и пустая история.

Дополнительно проверены настоящие запросы «Матрица», «Во все тяжкие», «Унесённые призраками», «Интерстеллар» и «Слово пацана». Список исключений популярной главной больше не скрывает поиск и не запрещает открытие ссылок, для которых API отдаёт плееры. Точное совпадение названия получает приоритет. Неинтерактивная надпись над обзорной сеткой удалена по запросу пользователя, сортировка и жанры сохранены.

Проверены выход F11 из HTML fullscreen и вход в fullscreen с открытым меню провайдеров. События клавиш для этих проверок отправляются нативным WebContents.sendInputEvent: CDP keyboard не воспроизводит Electron before-input-event. При открытом меню нативное видео становится видимым и растягивается на экран.

Версия 0.4: финальное направление — liquid glass по выбору пользователя. MeshGradient удалён, используются Glass в строке поиска и FlutedGlass / StudioBackground на фоне. Фоновый GPU-эффект отключается при просмотре и reduced motion; есть сохраняемый переключатель. Проверены меняющиеся пиксели в обеих темах. Иконки заменены на Material Symbols Rounded (31 глиф); поиск математически центрирован в рабочей области. Исходный пользовательский PNG логотипа включён без изменений, слоган удалён. Жёлтая внешняя рамка фокуса заменена изменением фона.

После смены оформления заново прошли 15 экранов общего аудита и обе темы с полноэкранными сценариями, включая открытое меню и выход F11 из HTML fullscreen. После перехода API и загрузки фильтров на Chromium шесть прерванных ответов обработаны без падения при принудительно отключённом Node fetch.

Узкая боковая панель проверена в обеих темах: подписи скрыты, доступны иконки и title-подсказки, выбор сериалов работает. Поиск остаётся центрированным в изменившейся рабочей области. После разворачивания и сворачивания bounds нативного плеера соответствуют DOM-области; полный экран по-прежнему скрывает панель, выход восстанавливает узкий режим. Режим переживает перезапуск. Отчёт `test-results/sidebar/report.json`.

После уточнения пользователя в узкой панели используется отдельный PNG-монограммы с потёртостями; обрезка полного логотипа удалена. Стрелка скрыта вне области логотипа, появляется при hover или focus-visible. Проверены оба состояния и сохранение режима. У прокрутки убраны нативные стрелки и непрозрачная дорожка; событие scroll показывает тонкий thumb на 900ms, затем скрывает. Проверены CSS дорожки/кнопок и добавление/удаление состояния is-scrolling.

Проверки 0.5: в обеих темах большой поиск по центру окна; живой поиск «Молодого Шерлока»; стрелки баннера и горизонтальной ленты; уникальные ID постеров на главной; сохранение ожиданий и однократный переход к уведомлению. Баннер допускает только горизонтальные обложки; широкие изображения в портретных карточках заменяются афишей.

Alloha: проверено реальное видео с ABP, «Молодой Шерлок» 3840×1600 и «Интерстеллар» 3840×2160; одинаковый User-Agent HTTP и всех iframe. Collaps: смены 1080→480→1080 без перезагрузки документа и потери позиции; отдельно вторая серия на 90-й секунде, пауза, скорость 1.25 и сохранение HTML fullscreen при переходе на 720p. Системный Esc проверен физическим вводом для fullscreen окна; проверку физического Esc из HTML fullscreen прервал инструмент компьютерного управления, поэтому для него остаются автоматические проверки и проверка размеров окна.

Версия 0.5.1: SourceDemo и его CSS загружаются при открытии справки, SearchSurface — отдельно от диалога, шейдер фона — после первого рендера в idle-период. Собранная версия прошла светлую/тёмную тему, справку stageshow, большой поиск и каталог. Измерено видимое интерактивное окно за 690–718 мс; перенос упаковки в установщик исключает распаковку приложения при каждом запуске.
