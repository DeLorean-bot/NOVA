# Support NOVA

[Project](../README.md) · [Releases](https://github.com/DeLorean-bot/NOVA/releases) · [Страница на русском](../README.ru.md)

If NOVA is useful to you, you can support development with Litecoin. To donate, copy the address or scan the QR code in your wallet. Select the **Litecoin (LTC) network**.

```text
ltc1qa7trnekjehy5qq4pgu2fanjje9s8k4pnndekmn
```

[![Scan in a Litecoin wallet](litecoin-qr.png)](litecoin-qr.png)

## Поддержать NOVA

Если NOVA вам полезна, вы можете поддержать разработку переводом Litecoin. Скопируйте адрес выше или отсканируйте QR-код в кошельке. Выберите **сеть Litecoin (LTC)**. Сумму вы указываете сами.
